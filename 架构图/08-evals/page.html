这个部分负责什么

ChatAgent 检索质量的回归基线：提交即返回 eval_id 后台执行；begin_nested 保存点内运行生产 ChatAgent + 全套工具（evaluation_mode），收集预检索与二次检索证据；Ragas 0.4 Collections 计算五项门禁指标；硬规则全部通过且指标达 RAGAS_*_MIN 才 passed。

关键机制

  • 执行状态与质量状态分离：Judge 失败是评测不完整（incomplete），不是质量结论。
  • rescore 只重算异常项，不重跑 ChatAgent（agent_reused=true）；回归对比要求评测集 Hash / Ragas 版本 / Judge / top_k 一致。
  • 失败 Case 一键生成 create_issue ActionDraft 进入人工确认。
  • 状态机：queued→running→passed/failed/error/no_cases（partial 见卡片）；重启清扫遗留 run 为 error。
