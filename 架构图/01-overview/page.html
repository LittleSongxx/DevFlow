这个部分负责什么

整个系统的运行时拓扑：用户经 Next.js 前端调用 FastAPI 后端；PostgreSQL 为唯一持久化存储（业务数据 + pgvector 向量同库）；GitHub 提供双向通道（REST 拉取 + Webhook 推送）；LLM 走 OpenAI 兼容接口，百炼提供 embedding 与重排。

关键机制

  • docker compose 一键编排 3 个服务（pgvector 版 PostgreSQL + 后端 + 前端），全部仅绑定 127.0.0.1（前端 3001 / 后端 8000 / PostgreSQL 调试端口 5433）。
  • 设置 DEVFLOW_API_KEY 后所有 /api/* 需要 X-API-Key；前端镜像在构建期内联该 Key。
  • 后端 lifespan 启动时执行 Alembic 迁移（advisory lock 防并发）、清扫遗留后台任务、启动周期同步 asyncio 任务。
