这个部分负责什么

GitHub 数据进入系统的唯一通道：接入时 token Fernet 加密落库并完成首次同步；调度器默认每 300s 轮询、Webhook 六类事件即时触发；同步在 per-repo 锁内串行拉取 Issue/PR/CI 实体并按唯一键 upsert；后台派生代码检出、代码图谱、项目文档索引与知识图谱。

关键机制

  • workflow_runs 仅失败 run 下载日志 zip（≤80000 字符）；jobs 含 steps 存 JSON。
  • 新插入走 SAVEPOINT，撞唯一键只跳过该条；PR 文件/评论与 jobs 先拉新数据成功再 delete+重插，失败保留旧数据。
  • 代码检出三种模式：managed shallow clone / local 工作树 / PR 独立 worktree 快照（168h 过期）。
  • 调度器失败指数退避 min(60×f, 600)s，循环永不退出（有测试验证）。
