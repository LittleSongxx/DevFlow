这个部分负责什么

三层控制面：入口防线（API Key 中间件、Webhook HMAC 验签、生产启动强校验）；应用内控制（Fernet token 加密、SSRF 主机白名单、日志脱敏、RBAC 四角色与审计）；对外写入唯一路径 ActionDraft → 人工确认 → GitHub 执行。

关键机制

  • 比较一律 hmac.compare_digest；Webhook 未配置 secret 仅开发放行；未匹配仓库统一 accepted=false 防枚举。
  • 全局 GitHub token 只发给 api.github.com；跨主机重定向剥离 Authorization，禁止自动跟随。
  • 脱敏 5 类模式（gh token / sk- / URL token / user:pass / Bearer）；sanitize_error 截断 600 字符。
